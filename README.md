## 📖 Project Overview

AURA AI is a conceptual AI-powered productivity platform designed to bring work, automation, AI assistance, and productivity insights into one workspace.

The website presents the product through a polished SaaS marketing experience designed to communicate the product value clearly and guide users toward conversion-focused actions.

## 🎯 Project Goals

- Create a premium and modern SaaS landing page
- Communicate the product value clearly
- Establish a strong visual hierarchy
- Create a responsive experience across devices
- Add meaningful interactions and micro-animations
- Demonstrate UI/UX design and front-end development together

## ✨ Key Features

- Responsive navigation
- Mobile navigation menu
- Sticky/scroll-based navbar interaction
- Hero section with interactive dashboard visual
- Product feature sections
- AI assistant presentation
- Smart automation presentation
- How It Works section
- Pricing section
- Monthly / Yearly pricing toggle
- Scroll-reveal animations
